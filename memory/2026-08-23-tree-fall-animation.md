# 树木砍伐倒下动画序列帧

- 修改内容：以现有 32×64 橡树为原型制作 16 帧硬像素砍伐动画；前 3 帧表现受击回摆，中段绕树根向右加速倒下，末段包含一次轻微回弹并停稳后消失。
- 影响范围：新增 `art/resources/resource_tree_oak_fall_16f.png`，尺寸为 1536×96，每帧 96×96，使用 RGBA 透明背景。树的静态视觉仍为 1×2 Tile；为容纳绕根旋转全过程，动画视觉画布为 3×3 Tile；点击区域仍为 32×64，逻辑树根占地按 1×1 Tile 处理。
- 交互约定：每次有效左键点击通过公开入口 `register_hit()` 只触发一次视觉节点震动，方便后续正式采集系统复用；震动期间忽略重复输入；第三次点击完成震动后播放 `fall`，避免 Tween 与序列帧同时抢占位置。动画为 12 FPS、非循环，最后一帧额外停留约 0.25 秒后删除树节点。
- 导入约定：图集保持最近邻过滤、关闭 Mipmaps、关闭 Repeat；`tree_fall_frames.tres` 按 16 个 96×96 横向区域切帧。
- 验证方式：运行主场景后连续点击同一棵树三次，确认每次点击有清晰震动、第三次震动结束后树向右倒下、停稳片刻并消失；Godot 4.7.1 MCP 项目启动与调试输出为零错误，另以临时烟雾测试依次调用三次 `register_hit()` 并等待完整动画，确认树节点最终释放（测试通过后临时文件已删除）。
