# 基地五卡召唤、战斗开箱与建筑红绿预览

- 基地“召唤”恢复原有付费五卡逻辑：消耗 10 金币，按基地等级品质概率生成五张纯战斗单位卡牌；支付后卡牌界面不可通过空白取消，必须选择一张。服务端保存一次性 offer 并校验卡牌 ID，客户端不能伪造结果。
- 英雄台保留独立的定向英雄入口：点击已完成英雄台展示全部英雄，首次消耗 2 张召唤符、替换消耗 1 张。基地随机五卡与英雄台唯一英雄是两条并存的召唤路径。
- 宝箱是仅由玩家指定攻击的中立目标，不加入战斗单位自动索敌列表。选中战斗单位后右键可见宝箱，单位复用指定攻击和寻路逻辑走到攻击距离；宝箱生命为 1，首次有效攻击触发开启动画并把奖励发给攻击玩家。
- 领地内实体宝箱在生成时注册确定性战斗 ID；领地外流送宝箱在玩家右键后由房主按资源 ID 权威实体化并可靠 RPC 到客户端。实体化会从流送数据和外部寻路障碍中移除原标记，再以正式宝箱节点继续参与碰撞和攻击。
- 建筑列表选择不再校验工人当前位置、资源或邻近资源条件，始终进入 2×2 选址预览。WASD 每次都允许移动一格；当前位置满足所有条件时预览为绿色，不满足时为红色并显示具体原因。
- 建筑确认时才执行本地提示和服务端最终校验。红色位置确认不会关闭预览，玩家可以继续 WASD 调整；绿色位置确认后才预扣资源并命令工人前往施工。
- 本文档替代 `2026-08-28-resource-loop-hero-altar-wild-monster.md` 和 `2026-08-28-builder-walk-construction-imagegen-buildings.md` 中“基地召唤只显示英雄台说明、旧随机召唤关闭”的现行规则；英雄台本身的 2/1 张召唤符规则仍有效。
