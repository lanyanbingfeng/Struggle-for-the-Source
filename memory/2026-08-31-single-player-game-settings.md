# 单人游戏设置与三档地图大小

## 已确认实现

- 点击主菜单“单人游戏”不再立即开局，而是打开独立设置面板；面板分别提供人机难度、地图大小和野怪强度，确认“开始远征”后才生成世界。
- 人机难度与野怪强度均为简单、普通、困难、地狱四档，二者独立传递；人机档位只控制 `SimpleAIController`，野怪档位控制野怪与世界 BOSS 的战斗倍率。
- 地图大小为小 100×100、中 250×250、大 500×500 三档，默认大地图；旧 1000×1000 值不再是受支持档位，并会规范化为 500×500。
- 地图尺寸通过单人快照的 `settings.map_size_tiles` 传给主地图。草地范围、相机边界、战争迷雾、资源流送、寻路、移动夹取、野怪/BOSS 出生范围都会按本局尺寸配置。
- 100×100 下初始两块 20×20 领地会使用动态边距摆放，不越界、不重叠；人机会从己方领地周围寻找合法扩张位置，不再依赖旧的固定扩张矩形。
- 本文档替代旧记忆中的“单人按钮右侧直接选择难度”“单人难度同时控制野怪”和“主地图固定 1000×1000”现行规则；旧文档保留为历史记录。

## 配置位置

- 三档地图定义：`game/data/map_size_setting.gd`
- 单人设置面板：`game/ui/main_menu.gd`
- 地图参数传递与世界边界：`game/main/map_demo.gd`
- 动态默认边界：`game/world/fog_of_war.gd`、`game/world/world_resource_streamer.gd`
- 自动验证：`tests/map_size_settings_smoke_test.gd`、`tests/ai_difficulty_smoke_test.gd`

## 验证事实

- Godot MCP 使用 4.7.2 启动 `res://game/main/main.tscn`，无脚本解析错误和运行错误。
- `MAP_SIZE_SETTINGS_SMOKE_TEST: PASS`：100/250/500 三档均正确配置草地、镜头、迷雾、资源流送和寻路边界，两块初始领地合法，且可生成五只野怪、世界 BOSS 和人机扩张位置。
- `AI_DIFFICULTY_SMOKE_TEST: PASS`：点击单人按钮会显示面板，三项选择数量和默认值正确，面板信号能把独立的人机/地图/野怪设置传给主地图。
- `GAMEPLAY_REGRESSION_OK`、`WORLD_BOSS_REGRESSION_OK`、`RESOURCE_NAVIGATION_REGRESSION_OK`：默认 500×500 下原有玩法、BOSS 和寻路回归通过。

## 手动复验

1. 点击“单人游戏”，确认出现人机难度、地图大小、野怪强度三行设置，地图行依次为小 100×100、中 250×250、大 500×500。
2. 分别用三档地图开局，开启开发者全图并滚动到边缘，确认世界边界随档位变化。
3. 选择不同的人机难度和野怪强度，确认人机名称/节奏使用人机档，野怪与 BOSS 属性使用野怪档。
