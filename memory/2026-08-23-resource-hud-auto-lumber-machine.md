# 资源 HUD 与自动伐木机器

- 修改内容：新增场景内 `ResourceManager` 节点和左上角 `ResourceHud`，显示金币、木材、石头、铁矿；开发模式金币初始值固定为 9999，其余资源初始为 0。
- 修改内容：基地菜单的 `recruit` 操作只生成一台伐木机器，机器出生点为基地中心下方 `Vector2(0, 64)`，并自动选择最近的健康树木。
- 采集规则：伐木机器到达树边后每秒调用树的 `register_hit()`；树保留原有三次命中和倒下动画，倒下动画完成时发出 `felled` 信号，地图通过资源管理器结算木材 +10、金币 -1。
- 脚本整理：资源数值、资源 HUD、伐木机器行为分别位于 `resource_manager.gd`、`resource_hud.gd`、`lumber_machine.gd`；新节点之间使用基础节点类型和方法/信号连接，规避编辑器脚本重载时的 `class_name` 注册顺序问题。
- 验证方式：Godot 4.7.1 MCP 启动主项目，调试输出无错误；通过点击基地→招募验证机器生成，等待机器自动完成三次砍伐后确认 HUD 木材增加 10、金币减少 1。
