# 基地 UI 跟随、A* 寻路与树人卡牌

## 世界锚点 UI

- `BaseActionMenu` 和 `SummonCardMenu` 不再只保存点击瞬间的屏幕坐标，而是保存当前 `PlayerBase` 节点；显示期间每帧通过 `get_global_transform_with_canvas().origin` 换算基地屏幕位置。
- 相机滚动或窗口画布变换后，基地按钮和召唤卡牌都会重新定位并保持视口边缘裁剪。基地节点失效或菜单关闭时清除引用。

## A* 寻路与物理阻挡

- `game/world/world_pathfinder.gd` 使用覆盖 100×100 Tile 地图的 `AStarGrid2D`。它扫描运行时基地、树木和石头容器内的 `CollisionShape2D`，把形状包围格标记为不可通行，并使用“有障碍时禁止斜穿角落”的对角规则。
- 房主先生成多选方阵终点，再从每个己方战斗单位当前位置分别计算路径；目标格被占用时会寻找最近可通行格。完整 `PackedVector2Array` 路径和最终目标通过原有权威移动 RPC 同步。
- 树人沿路径点逐段 `move_and_slide()`。基地、树木和石头均增加碰撞层 2 的 `StaticBody2D`，与树人碰撞体形成寻路之外的第二层防穿模保护。
- 树木或石头移除后会延迟重建阻挡格，使已采空位置恢复可通行。

## 树人卡牌

- 卡牌最终尺寸从 92×112 缩小为 80×104。`art/ui/cards/card_treant_art.png` 使用玩家提供的 1254×1254 RGBA 树人插画；世界单位仍使用原生 32×32 资源，两者职责分离。
- `art/ui/cards/card_background_80x104.png` 是根据 ImageGen 通用木质藤蔓卡框方案按最终 80×104 原生尺寸整理的 RGBA 像素资源；中心留空，可复用于其他单位。
- 鼠标悬停卡牌会在卡牌行下方显示详情。树人当前数据为坦克定位、生命 320、攻击 22、防御 48、视野 7 格、移速 92，并说明高生命高防御、低攻击的前排特点。
- `UnitDefinition` 新增 `role_name`、`description`、`max_health`、`attack` 和 `defense`，后续单位可直接在 `.tres` 中配置卡牌详情。

## 验证记录

- 单进程回归在移动相机后确认基地按钮与五张卡牌仍对齐基地；卡牌尺寸、玩家插画、悬停属性和介绍均通过断言。
- A* 回归识别 73 个阻挡格，树人使用 6 个路径点绕过树木，移动过程中未进入阻挡格；三单位编队终点互不重叠且均可通行。
- 双 Godot 4.7.2 进程网络回归中，房主和客户端退出码均为 0，确认 `PackedVector2Array` A* 路径可通过权威 RPC 同步。
- 卡牌界面经过运行时截图检查：五张卡牌均保持可见，详情面板位于卡牌行下方，不遮挡其他卡牌。
- 临时回归场景、脚本和项目内预览文件已逐个清理。
