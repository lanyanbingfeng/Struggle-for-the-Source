# 第二领地场景可见性修复

- 问题原因：`main.tscn` 原先只保存空的 `Territories` 和 `TestBases` 容器，领地及玩家2基地依赖父场景 `@tool` 脚本临时创建；`player_territory.gd` 本身不是 `@tool`，导致编辑器预览不稳定。第二领地原点还位于玩家1右侧 50 Tile，初始镜头无法看到。
- 修复内容：`Player1Territory`、`Player2Territory` 和 `TestBase2` 改为 `main.tscn` 持久节点；领地脚本启用 `@tool` 并导出玩家编号、格子矩形和标识色，编辑器与运行时使用同一配置。
- 测试布局：玩家1领地原点保持 `(15, 40)`，玩家2调整为 `(37, 40)`，两块 20×20 领地水平相邻并间隔 2 Tile；公平资源的相对坐标、数量和 `territory_id` 隔离规则不变。
- 镜头规则：测试初始镜头位于两个基地中点 `(1168, 1616)`，缩放为 `0.75`，开始游戏和重置状态时都会恢复该双领地概览。
- 验证方式：使用 Godot 4.7.2 MCP 启动主项目，场景资源和脚本解析成功，调试输出无错误。
