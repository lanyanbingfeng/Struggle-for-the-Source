# 基地操作菜单交互

- 修改内容：新增基地点击操作菜单，支持招募、召唤、升级三个可扩展按钮；按钮从基地视觉操作点出发，向横向最终位置移动并线性放大，不使用透明度渐变。
- 影响范围：`base_action_menu.gd`、`base_action_menu.tscn`、`map_demo.gd`、`project.godot`；菜单使用手动横向布局，中心按钮与基地操作点对齐，按钮最终位置向上偏移，项目默认全屏运行。
- 使用约定：按钮尺寸为 66×24；新增按钮通过 `BaseActionMenu` 的配置数组追加，不修改布局动画逻辑。基地操作点相对基地交互中心偏移 `Vector2(4, -12)`。
- 验证方式：通过 `@coding-solo/godot-mcp` stdio 服务使用 Godot 4.7.1 运行项目，调试输出无错误。
