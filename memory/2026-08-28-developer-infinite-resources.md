# 开发者无限资源模式

- 开发者面板新增“无限资源”开关，与显示全图、暂停人机并列。
- 开启后仅作用于操作该开关的玩家，金币、木材、石头、铁、召唤符、技能经验和经验立即设为 999999；每次权威资源状态同步时自动回填，因此消费后仍保持 999999。
- 局域网模式由客户端向房主请求切换，房主维护各玩家的无限资源状态；不会自动赋予其他玩家或人机无限资源。
- 关闭后停止自动回填，保留关闭时已有的资源数值；返回主菜单或重开一局会重置开关与状态。

## 验证

- 使用 Godot 4.7.2 解析项目，无脚本解析错误。
- 运行 `res://tests/gameplay_regression_test.tscn`，进程退出码为 0。
- 进入游戏后勾选右上角“开发者：无限资源”，确认七类资源显示 999999；执行招募、建造或升级后确认数值仍为 999999。
