# 局域网错误密码弹窗修复

## 已确认修复

- `game/ui/lan_lobby.gd` 在大厅壳层中持有一个 `AcceptDialog`，任何 `LanSession.action_rejected` 都会显示明确的模态错误提示。
- 客户端提交错误房间密码时，弹窗正文为房主返回的“房间密码错误”，玩家点击“确定”后关闭。
- `game/systems/lan_session.gd` 会区分“加入请求已被房主拒绝”和“已在房间中但房主断开”两种情况；密码错误后的 ENet 断开不会再发出泛化的“加入房间失败”覆盖原始原因。
- 处于空闲或浏览状态时收到延迟的断开信号会被忽略，避免玩家主动离开后出现误报。

## 验证方式

- 使用两个独立 Godot 4.7.2 进程运行密码提示冒烟测试：房主创建带密码房间，客户端自动发现后提交错误密码。
- 客户端已确认错误弹窗可见，并且在断开与恢复房间搜索后正文仍保持“房间密码错误”；房主与客户端均输出 `PASSWORD_PROMPT_SMOKE PASS`，日志无错误。
- 临时冒烟测试场景和日志已逐个清理。
