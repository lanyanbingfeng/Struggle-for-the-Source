# 资源、单位与建筑详细战术地图

## 已确认实现

- `TacticalMapView` 的数据源从单一单位数组扩展为 `units`、`resources`、`buildings`、`territories` 四类情报，并只在地图打开时按 0.4 秒刷新。
- 地图用独立图形和颜色绘制树木、石头、铁矿、宝箱、工人、战斗单位、英雄、野怪、世界 BOSS、基地和生产建筑；选中单位带高亮，放大后单位与建筑显示生命条，施工建筑显示叉形状态，交战目标继续显示红色波澜。
- 地图顶部提供实时数量摘要和图例。鼠标悬停标记时显示名称、阵营、生命、资源剩余量、建筑等级/施工进度/待领取量和交战状态。
- `WorldResourceStreamer.get_all_resource_data()` 提供未实体化世界资源的只读副本。`MapDemo` 将该坐标数据与领地内或已实体化资源合并，避免区块流送以外的资源从战术地图中消失。

## 战争迷雾规则

- 资源只有对应世界位置已经探索后才进入地图，可在视野离开后继续保留。
- 己方单位、基地和建筑始终显示；非己方单位、野怪、BOSS、基地和建筑仅在当前视野中显示，避免泄露实时敌情。
- 领地边界在任意格被探索后显示；`FogOfWar.is_cell_rect_explored()` 用于该相交查询。
- 开发者全图模式沿用 `FogOfWar` 当前全图显示规则，不会永久写满探索位图。

## 验证事实

- Godot MCP 使用 Godot 4.7.2、Forward Mobile 启动主项目，无脚本解析、资源加载或运行错误。
- `TACTICAL_MAP_ALERT_TEST: PASS`：覆盖四类地图情报缓存、资源/单位/基地/领地图例数据、滚轮缩放、点击定位、M 键开关和领地探索相交查询。
- `GAMEPLAY_REGRESSION_OK`：真实单人开局必须返回已探索资源、基地/建筑和领地情报，并逐个验证资源位置已经探索。
- `MAP_SIZE_SETTINGS_SMOKE_TEST: PASS`、`RESOURCE_NAVIGATION_REGRESSION_OK`、`FACTION_TINT_SMOKE_OK` 均通过。

## 人工复验

1. 开始单人游戏后按 M，确认己方领地内的资源、基地和单位出现，未探索区域保持黑暗且不显示资源。
2. 探索树林、石区、铁矿或宝箱后离开视野，再打开地图，确认已探索资源仍保留。
3. 建造任意生产建筑并招募工人、战斗单位和英雄，确认地图图形不同；放大地图并悬停，检查生命、阵营、施工或资源状态。
4. 让敌方单位进入视野并交战，确认红色波澜出现；敌方单位或建筑离开当前视野后应从地图消失。
