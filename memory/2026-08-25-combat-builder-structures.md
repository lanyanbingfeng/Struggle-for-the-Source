# 不可取消召唤、共享战斗组件与建筑工人

## 已确认事实

- 付费召唤卡牌使用强制选择模式：点击空白不能关闭；普通招募仍可点击空白取消。返回主菜单等流程使用强制关闭入口清理 UI。
- `UnitDefinition` 现已集中配置攻击、防御、生命、攻速、攻击距离、追击范围、闪避、移速、魔法上限/恢复和技能参数；同类单位实例引用 `unit_catalog.tres` 中同一份 `.tres` 资源，不复制静态属性。
- `HealthComponent` 保存每个实体独立的生命、魔法、防御和闪避运行时状态；`HealthBar2D` 为单位、基地和生产建筑绘制世界空间生命条，拥有魔法的单位额外显示魔法条。
- 战斗逻辑只在房主/单人权威端运行。敌人首次进入攻击范围后必须累计完整攻速间隔才会攻击，离开范围会重置计时；目标离开配置的追击范围后，战斗单位返回开战前位置。
- 伤害按 `max(1, 攻击-防御)` 结算，闪避由权威端随机判定；单位、基地和生产建筑死亡通过可靠 RPC 移除。0.1 秒状态快照同步单位生命/魔法以及基地、建筑生命。
- 树人的“光合作用”自动治疗技能只从附近友方单位中选择生命百分比最低者，消耗并自动恢复魔法；施法后树人自身移动速度按配置短暂降低。
- 召唤池新增剑士：高攻击、1.9 秒攻速、低生命/防御、1.1 格近战距离、8 格追击、126 移速、30% 闪避。
- 招募池新增建筑工人。选中后右下角“建筑”按钮提供伐木场、采石场、铁矿场、金矿场、钻石场和金币生产台六类 2×2 建筑。
- 建筑只能在建筑工人当前位置生成，必须完整位于所属己方领地，不能与基地或已有建筑重叠；前五类还要求配置半径内有对应资源点。费用、生命、防御、条件、产量和生产间隔由 `BuildingDefinition` `.tres` 统一配置。
- 生产建筑由房主权威计时产出资源；建筑生成、资源扣除、生命同步和死亡均走服务端校验。
- 探索者建基地的确认 UI 已从屏幕中央移动到右侧窄栏；资源 HUD、提示 UI 和单位面板整体缩小，避免遮挡 20×20 领地预览。

## 美术与尺寸

- 剑士、建筑工人正式资源为原生 32×32 RGBA PNG，逻辑占地均为 1×1 Tile。
- 六类生产建筑复用一张原生 64×64 RGBA 模块化工坊资源，通过色调和资源字标区分，逻辑占地和最终文件尺寸均为 2×2 Tile。
- ImageGen 只用于剑士、建筑工人和工坊的高分辨率概念参考；正式游戏资源由 `art/sources/generate_unit_and_building_assets.gd` 在原生尺寸重绘，未直接缩小 AI 大图。
