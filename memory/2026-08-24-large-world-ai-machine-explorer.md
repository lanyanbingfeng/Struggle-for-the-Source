# 百万格世界、人机、机器升级与探索者扩张

## 已确认实现

- 主地图为 1000×1000 Tile（32000×32000 像素）。草地由一个启用 Repeat 的 `Sprite2D` 覆盖全图，不创建一百万个 Tile 单元。
- 两块初始 20×20 领地仍按相同相对坐标生成树、石头和稀有矿物，保证玩家与人机初始资源绝对公平。
- 领地外按稀有度递减生成树木、石头、铁矿、金矿和钻石。标准档按 20×20 分区生成约 2500 个轻量 `WorldResourceMarker`；标记进入新领地后才转换成带碰撞和采集脚本的正式资源实体。
- 战争迷雾颜色透明度为 0.46，只绘制当前视口涉及的格；本玩家拥有的全部领地都永久可见。
- 1000×1000 地图不再使用整图 `AStarGrid2D`。`WorldPathfinder` 只保存实际碰撞占用格，并按需生成直线路径与绕行点，避免百万节点内存开销。本决策替代旧的“100×100整图A*”实现。
- 单人快照包含玩家1和人机2。人机初始招募伐木机、采石机和探索者，会采集、升级、探索建基地、召唤战斗单位并向玩家基地移动。
- 开发者面板提供“暂停人机”；暂停时 AI 决策计时和所有人机单位物理处理同时冻结，恢复后继续。
- 伐木机与采石机出生默认工作，左键选中后显示工作/休息和升级命令。休息时才能手动移动；机器目标由服务器限制在所属领地，越界时提示并夹到边界。
- 两类机器最高 Lv.4，速度倍率为 1.00/1.30/1.65/2.10。升级费用始终包含金币、木材和前一级可采矿物。
- 采石机权限为 Lv.1石头、Lv.2铁矿、Lv.3金矿、Lv.4钻石。
- 探索者招募费用为 500 金币，可离开领地。建造预览会绘制20×20范围、将镜头缩放至0.42、统计覆盖资源；服务器确认地图边界、领地重叠、单位所有权和单位位置后创建新领地与基地。
- 探索者生产美术为 `art/units/unit_explorer_1x1.png`，原生32×32 RGBA、透明背景、Nearest导入，逻辑与视觉占地均为1×1 Tile。

## 配置位置

- 地图、全图资源、领地扩张和权威 RPC：`game/main/map_demo.gd`
- 机器等级、费用、倍率和采矿权限：`game/data/machine_progression.gd`
- 人机节拍：`game/systems/simple_ai_controller.gd`
- 单位命令和建造确认：`game/ui/unit_command_panel.gd`
- 稀疏路径：`game/world/world_pathfinder.gd`
- 半透明视野：`game/world/fog_of_war.gd`
- 探索者：`game/units/explorer_unit.gd`、`game/data/explorer_definition.tres`

## 验证事实

- Godot MCP 使用 4.7.2 启动 `res://game/main/main.tscn`，调试输出无脚本解析错误和运行错误。
- 无界面单人局集成检查得到：地图1000、两块初始领地、约2500个全图资源、3个人机初始工人；AI暂停能冻结单位；休息机器越界目标夹到玩家领地边界；采石机可连续升级到Lv.4；探索者建基地后领地数从2变3，覆盖资源成功归属新领地。
- 探索者 PNG 检查结果为32×32、RGBA、Alpha范围0～255。

## 手动验证

1. 启动单人游戏，右上角打开“显示全图”，向地图外部滚屏，确认各分区都能遇到资源且钻石明显最少。
2. 切换“暂停人机”，确认人机机器和探索者停止；取消后继续。
3. 招募机器，选中后点休息，再右键领地外，确认出现越界提示且机器朝边界移动。
4. 准备升级资源，将采石机升至Lv.2/Lv.3/Lv.4，依次确认铁矿/金矿/钻石目标解锁。
5. 招募探索者并移动到现有领地外，点“建造基地”，检查镜头拉远、黄色预览框、资源统计和确认后生成的新基地/领地。
