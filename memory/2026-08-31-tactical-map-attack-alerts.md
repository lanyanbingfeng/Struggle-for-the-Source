# 探索战术地图与单位受击提醒

## 战术地图

- 游戏进行中按 M 打开或关闭 `TacticalMap`；Esc 也可关闭已打开的地图。地图使用独立 `CanvasLayer`，单人与多人模式都不会改变权威模拟或暂停规则。
- `FogOfWar` 使用按本局地图尺寸分配的 `PackedByteArray` 保存永久探索状态，同时维护一张每格一像素的 `ImageTexture` 供地图绘制。己方领地与单位实际视野会写入探索记录；开发者“显示全图”只影响当前显示，不会把整图永久写入探索历史。
- 地图始终显示己方单位；敌方单位、蜘蛛精英和世界 BOSS 只有当前仍在本地视野中时才显示，避免客户端通过战术地图获取战争迷雾外的实时位置。
- 战术地图支持 1～8 倍、以鼠标位置为中心的滚轮缩放。左键点击地图会关闭地图，并通过 `EdgeScrollCamera.jump_to_world_position()` 把主视角移动到对应世界坐标；最终位置仍受地图边界限制。
- 战斗单位、精英和 BOSS 的 `in_combat` 状态加入 0.1 秒状态快照；地图为正在战斗的标记绘制循环红色波澜。客户端只显示同步状态，不自行推断权威战斗目标。

## 受击提醒

- `HealthComponent` 新增强类型 `damaged` 信号，伤害入口携带攻击来源说明。普通攻击、配置技能、持续伤害、蜘蛛技能和世界 BOSS 三项技能均提供具体中文来源。
- `MapDemo` 只为玩家单位连接受击提醒；房主在确认敌对伤害后，本地直接显示，远端则通过可靠定向 RPC 只通知单位所属玩家。
- `AttackAlertHud` 在右下角最多显示 4 条提醒，内容包括目标单位、攻击来源和本次伤害；同一单位 6.5 秒内连续受击会合并计数并刷新最新位置。点击提醒会移动视角到目标最后一次受击位置并移除该提醒。

## 验证事实

- Godot MCP 使用 Godot 4.7.2、Forward Mobile 启动 `res://game/main/main.tscn`，无脚本解析、资源加载或运行错误。
- `TACTICAL_MAP_ALERT_TEST: PASS`：覆盖永久探索、探索纹理、地图滚轮缩放、地图点击坐标、M 键开关、带来源伤害信号、连续提醒合并、提醒点击定位和镜头边界限制。
- `GAMEPLAY_REGRESSION_OK`、`WHITE_UNIT_SKILL_FRAMEWORK_TEST: PASS`、`MAP_SIZE_SETTINGS_SMOKE_TEST: PASS`、`WORLD_BOSS_REGRESSION_OK`、`RESOURCE_NAVIGATION_REGRESSION_OK`、`FACTION_TINT_SMOKE_OK` 均通过。

## 人工复验

1. 开始单人游戏，控制己方单位走出领地探索后按 M；确认走过的范围保留、未探索区域保持黑暗。
2. 在战术地图上滚轮缩放，点击任意地图位置；确认地图关闭且主视角移动到点击位置，边缘位置不会越界。
3. 让己方单位与敌方单位交战；确认地图单位点出现红色波澜，且敌军离开当前视野后不会继续显示在地图上。
4. 让敌方单位、蜘蛛精英和世界 BOSS 分别攻击己方单位；确认右下角显示具体攻击来源，连续攻击会合并，点击后视角移动到受击地点。
