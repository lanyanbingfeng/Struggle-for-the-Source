# 公平视野人机与四档难度

## 已确认实现

- 单人游戏开始按钮右侧提供简单、普通、困难、地狱四档人机难度，默认普通；选择结果写入单人快照并传给 `SimpleAIController`。
- 简单思考间隔为 4.2～5.4 秒，普通为 2.4～3.2 秒，困难为 0.9～1.4 秒；地狱不增加人工思考延迟，但每帧最多执行一个控制步骤，避免失败操作形成死循环。
- 一次思考最多执行一个扩张、召唤购买、召唤领取、移动、机器升级或基地升级操作，不再在同一节拍内瞬间完成整批操作。
- 所有难度都遵守同一套阵营视野：己方领地永久可见，己方单位按 `UnitDefinition.vision_radius_tiles` 提供圆形视野。开发者“显示全图”只影响本地画面，不会给人机提供信息。
- 人机只会攻击实际看见过的目标。移动敌人离开视野后，人机只保留最后已知位置，不会继续读取其实时位置；到达最后已知位置且没有重新发现目标时会清除该记忆。
- 未发现敌人时，战斗单位按与敌方位置无关的固定环形航点探索；难度同时将目标战斗单位数设为 2/4/6/8。

## 配置位置

- 难度枚举、名称和思考时间：`game/systems/simple_ai_controller.gd`
- 难度选择界面：`game/ui/main_menu.gd`
- 阵营视野、最后已知目标、单步决策和探索航点：`game/main/map_demo.gd`
- 自动验证：`tests/ai_difficulty_smoke_test.gd`、`tests/ai_difficulty_smoke_test.tscn`

## 验证事实

- Godot MCP 以 4.7.2 启动 `res://game/main/main.tscn`，调试输出无脚本解析错误和运行错误。
- `AI_DIFFICULTY_SMOKE_TEST: PASS`：确认四档间隔、默认普通、难度传递、单步操作、开局无法看见玩家基地、迷雾内移动目标只保留最后已知位置，以及进入视野后才发现玩家基地。
- `FACTION_TINT_SMOKE_OK`：现有本地阵营着色回归测试通过。
- 主场景无界面运行 180 帧，退出码为 0，标准错误为空。

## 手动复验

1. 在主菜单切换四档难度，开始单人游戏，确认人机名称带有所选难度。
2. 不开启“显示全图”，观察人机在未侦察到玩家前只扩张、发展和探索，不会直接朝玩家基地移动。
3. 用开发者全图观察普通难度，确认召唤购买、领取、移动和升级之间存在思考停顿；切换为地狱重新开局，确认步骤会立即连续执行。
4. 让玩家移动单位短暂进入人机单位视野后退出，确认人机只前往最后一次看见的位置，而不会在迷雾中持续追踪。
