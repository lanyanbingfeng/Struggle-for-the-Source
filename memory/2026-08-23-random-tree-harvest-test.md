# 随机树与临时砍伐测试

- 修改内容：在 100×100 草地地图中使用固定随机种子生成 80 棵树；树节点独立封装静态显示、底部 32×32 点击区域、三次点击计数、震动反馈和倒下后删除。
- 资源约定：树静态资源为 `art/resources/resource_tree_oak_1x2.png`，保持原始 32×64；倒下图集 `art/resources/resource_tree_oak_fall_16f.png` 为 1536×96，通过 `tree_fall_frames.tres` 按 16 个 96×96 横向区域整理为 SpriteFrames，原始静态树不修改。
- 测试边界：鼠标点击砍树仅为临时测试入口，后续正式采集系统接入时可删除树脚本中的输入和计数逻辑，不影响随机生成与动画节点。
- 分布约定：随机树避开基地中心及周边 5 Tile 缓冲区，并使用固定种子 `20260823` 保证测试可复现。
- 验证方式：Godot 4.7.1 headless editor load 和项目启动检查通过；运行项目后点击同一棵树三次验证震动、倒下动画和节点删除。
