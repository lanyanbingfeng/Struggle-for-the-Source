# 白色战斗单位特效显示缩放

- 18种新增白色战斗单位继续保留1774×887高清透明序列原图，不修改或重采样美术资源。
- `TreantUnit` 在装载高清生成特效时按单帧尺寸自动缩放：普攻最长边显示为约72像素，技能最长边显示为约144像素。
- 自动缩放只处理单帧最长边超过320像素的生成资源；树人和剑士原有64～256像素特效保持原尺寸。
- 缩放仅作用于 `AttackVfx` 和 `SkillVfx` 节点的视觉变换，不改变攻击距离、技能范围、碰撞、寻路或权威端伤害结算。

## 验证

- `WHITE_UNIT_SKILL_FRAMEWORK_TEST: PASS`，覆盖18种单位的普攻与技能显示缩放。
- `GAMEPLAY_REGRESSION_OK`。
- Godot 4.7.2主场景启动无脚本解析或资源加载错误。
