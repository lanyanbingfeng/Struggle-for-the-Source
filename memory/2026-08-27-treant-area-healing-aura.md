# 树人范围治疗与治疗光环

## 已确认决定

- 光合作用以施法树人为圆心，只要技能范围内存在受伤友方单位就会施放；一次施法只消耗一次魔法。
- 技能会对范围内所有存活友方单位调用治疗，包含施法树人自身；每个目标恢复其自身最大生命值的 10%，满血目标保持满血。
- 普通、稀有、史诗、传说四档树人的 `skill_heal_percent` 统一为 `0.1`，原有 3.25、3.5、3.75、4 格范围和各档魔法消耗、冷却、减速时长保持不变。
- 本规则替代历史记忆中“只治疗生命最低目标”和四档 10%/11%/12%/14% 的旧规则。

## 美术资源

- 树人技能仍使用 8 帧、4×2 的 `AnimatedSprite2D` 图片序列，但画面已替换为明确的绿色范围治疗光环：扩散圆环、向上生命能量和绿色/金色治疗十字闪光。
- 四档序列图继续使用 `art/vfx/treant_skill_green_particles_r104_8f.png`、`r112`、`r120`、`r128` 稳定路径；单帧分别为 208、224、240、256 像素，对应实际技能直径。
- 正式 PNG 使用 RGBA 透明背景、二值 Alpha、最近邻重采样，无运行时缩放；场景保持 Nearest 纹理过滤和无 Mipmap 导入。

## 验证方式

- `tests/gameplay_regression_test.tscn` 会验证范围内建筑工人、剑士与施法树人自身均精确恢复 10% 最大生命，魔法只消耗一次，四档配置统一为 10%，四档序列尺寸与二值 Alpha 正确；Godot 4.7.2 Mobile 实跑输出 `GAMEPLAY_REGRESSION_OK`，无错误。
- `tests/card_ui_smoke_test.tscn` 实跑输出 `CARD_UI_SMOKE_TEST: PASS`，无错误。
- 使用 Godot MCP 启动 `game/main/main.tscn`，资源导入、脚本解析和运行输出均无错误。
