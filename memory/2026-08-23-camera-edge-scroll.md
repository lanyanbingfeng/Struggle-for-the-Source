# 鼠标边缘滚屏视角

- 修改内容：为现有 `MapCamera` 增加鼠标边缘滚屏功能，鼠标进入屏幕边缘区域后视角连续移动，越靠近边缘移动强度越高。
- 影响范围：新增 `camera_edge_scroll.gd`，并在 `main.tscn` 挂载；`map_demo.gd` 将当前 100×100 地图尺寸传给相机脚本。
- 使用约定：默认边缘触发比例为 `0.12`，移动速度为 `600.0`；相机根据视口尺寸、缩放和地图尺寸自动限制边界；鼠标悬停在可见 UI 控件上时暂停边缘滚屏。
- 验证方式：通过 `@coding-solo/godot-mcp` stdio 服务使用 Godot 4.7.1 运行项目，调试输出无错误。
