# 高清卡牌立绘与建筑选择美化

## 卡牌资源职责

- 地图单位继续使用原生 32×32 世界贴图；卡牌界面改用独立 1254×1254 UI 立绘，禁止再把地图贴图放大作为卡面。
- 玩家指定的伐木机、探索者、剑士、建筑工人和资源工坊原图保存在 `art/sources/card_art/`，正式卡面位于 `art/ui/cards/`。
- 伐木机源图的棋盘格原本被烘焙进 RGB 图片；正式卡面只做背景透明化，主体没有重画。其余四张源图直接保留原有 RGBA 透明通道。
- 当前采石机没有玩家指定的独立高清立绘，因此仍保留现有卡图；后续只有取得指定资源后再替换，不自动重新生成。

## 卡牌与建筑界面

- `SummonCardMenu` 卡牌尺寸为 104×136，卡面使用线性纹理过滤，并增加圆角暗色卡框、品质描边、阴影、工/战类型角标、品质角标和悬停缩放。
- 悬浮详情面板扩大为 292×204，保留品质、定位、生命、攻击、防御、攻速、攻距、闪避、追击、移速、魔法、招募费用和描述。
- 卡牌打开后的 150ms 内忽略背景关闭信号，避免基地按钮的同一次鼠标释放穿透并立即关闭卡牌菜单。
- `BuildingDefinition` 新增 `card_texture`；六种资源建筑选择按钮都使用玩家指定的资源工坊立绘，并按建筑 `tint` 显示独立强调色。

## 验证记录

- Godot 4.7.2 完整导入五张新增 PNG，所有正式卡图均有对应 `.import`。
- `tests/card_ui_smoke_test.tscn` 通过 Godot MCP 运行，输出 `CARD_UI_SMOKE_TEST: PASS`：确认四张招募卡、104×136 布局、高清纹理、点击保护和六个建筑图标。
- 主场景通过 Godot MCP 启动，调试输出 `errors: []`；验证完成后只停止调试游戏进程，保留用户编辑器。
