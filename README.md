# 争源

《争源》是一款基于 Godot 4.7 的 2D 像素风俯视角策略/资源经营原型。玩家将在地图中围绕基地进行资源建设、单位管理和持续扩张。

当前版本已经完成基础地图、基地交互、操作菜单和相机浏览功能，属于“核心交互原型”阶段。

## 当前开发进度

### 已完成

- 创建 100×100 Tile 的草地地图，地图尺寸为 3200×3200 像素。
- 使用 32×32 像素网格和 Nearest 像素导入配置。
- 在地图中心放置 3×3 基地，基地资源尺寸为 96×96 像素。
- 基地支持鼠标左键点击检测。
- 点击基地后弹出操作菜单，当前包含：
  - 招募
  - 召唤
  - 升级
- 操作菜单按钮支持统一配置、禁用状态和扩展按钮。
- 菜单按钮从基地操作点移动到最终位置，并执行线性放大动画。
- 鼠标移动到屏幕边缘时，相机自动滚动；越靠近边缘，移动速度越快。
- 相机根据地图边界自动限制移动范围。
- 鼠标悬停在 UI 控件上时，暂停边缘滚屏，避免操作菜单打开时误移动镜头。
- 已准备 1×1 伐木机器资源，最终尺寸为 32×32 像素。
- 已建立项目资源生成与导入规范，统一使用正交俯视角、左上光源和硬像素边缘。
- 已增加左上角资源 HUD，显示金币、木材、石头和铁矿；金币开发模式初始值为 9999。
- 基地点击“招募”后会在基地下方门口生成一台伐木机器，机器会自动寻找最近的树。
- 伐木机器在树边每秒调用一次树木砍伐入口，三次后复用现有倒下动画。
- 树木倒下并完成动画后，木材增加 10，金币减少 1。
- 已增加带像素风背景的全屏开始界面，支持单人游戏、多人游戏、设置、关于和退出游戏。
- 已增加游戏内 Esc 菜单，支持返回游戏、设置、返回主菜单和退出游戏。
- 单人模式打开 Esc 菜单时暂停游戏时间；多人模式打开菜单时游戏继续运行。
- 从游戏返回主菜单会清理当前单位、重置开发资源、重生树木并将相机复位到基地。

### 当前阶段

目前已经具备可以运行和体验的基础交互 Demo，但核心策略玩法仍处于搭建阶段。

“招募”“召唤”“升级”均已完成按钮、信号和事件分发流程；其中“招募”已经实际生成伐木机器并接入自动采集，资源结算由资源管理器统一处理。

## 游戏玩法概念

玩家以基地为核心，在地图上收集和管理资源，逐步发展自己的势力。

预期的基础玩法循环如下：

```text
浏览地图
  ↓
查看基地与资源分布
  ↓
点击基地
  ↓
选择招募、召唤或升级
  ↓
消耗资源并获得单位/能力/建筑强化
  ↓
继续扩张和争夺地图资源
```

### 基地操作

点击基地后，会在基地上方显示操作菜单：

- 招募：在基地下方门口生成一台伐木机器；重复点击不会重复生成。
- 召唤：计划用于召唤特殊单位、资源或战斗力量。
- 升级：计划用于提升基地等级、解锁能力或增强生产效率。

目前“召唤”和“升级”仍属于功能入口；“招募”已经接入伐木机器生成与自动采集流程。

### 地图浏览

- 地图采用正交俯视视角。
- 鼠标移动到屏幕四周会触发相机滚屏。
- 鼠标越接近屏幕边缘，滚屏强度越高。
- 相机不会移动到地图范围之外。
- 操作菜单打开时，将鼠标停留在按钮上不会触发相机滚屏。

## 操作方式

| 操作 | 说明 |
|---|---|
| 开始界面“单人游戏” | 进入单人地图，Esc 菜单会暂停时间 |
| 开始界面“多人游戏” | 进入多人地图，Esc 菜单不会暂停时间 |
| Esc | 在游戏中打开或关闭游戏菜单；弹窗打开时关闭弹窗 |
| 游戏菜单“返回游戏” | 关闭菜单并继续游戏 |
| 游戏菜单“设置” | 查看当前暂停规则说明 |
| 游戏菜单“返回主菜单” | 返回开始界面并重置本轮开发测试状态 |
| 游戏菜单“退出游戏” | 退出当前 Godot 游戏进程 |
| 鼠标左键点击基地 | 打开或关闭基地操作菜单 |
| 鼠标移动到屏幕边缘 | 移动地图视角 |
| 点击“招募” | 生成伐木机器并开始自动寻找树木 |
| 点击“召唤” | 当前输出 `summon` 操作事件 |
| 点击“升级” | 当前输出 `upgrade` 操作事件 |
| 点击菜单外区域 | 关闭基地操作菜单 |

## 运行项目

### 环境要求

- Godot 4.7，当前开发验证版本为 Godot 4.7.1。
- Windows 环境使用项目配置的 Mobile 渲染模式。

### 启动方式

1. 使用 Godot 打开项目目录：

   ```text
   D:/GodotProjects/争源
   ```

2. 打开项目后运行主场景或直接运行项目。
3. 项目主场景配置为 `res://game/main/main.tscn`。

也可以使用 Godot 命令行运行：

```powershell
Godot_v4.7.1-stable_win64.exe --path "D:/GodotProjects/争源" --editor
```

## 技术配置

- 引擎：Godot 4.7。
- 渲染器：Mobile。
- 纹理过滤：Nearest，关闭默认平滑过滤。
- 窗口视口：640×480。
- 窗口拉伸：`canvas_items`，比例模式为 `expand`。
- 地图：`TileMapLayer`。
- 相机：`Camera2D`。
- 基地交互：`Area2D` + `CollisionShape2D`。
- 菜单层：`CanvasLayer`。
- 3D 物理引擎配置：Jolt Physics；当前玩法主要为 2D。

## 资源规范

项目使用 32×32 像素作为基础 Tile 网格。

- 1×1 资源：32×32 像素。
- 3×3 资源：96×96 像素。
- Ground 使用不透明 PNG，并保持四边可平铺。
- 建筑、单位、资源和装饰使用透明 RGBA PNG。
- 像素资源关闭 Filter 和 Mipmaps，按用途配置 Repeat。
- 禁止使用运行时缩放弥补错误的资源尺寸。
- 生成或修改资源前，必须阅读 [资源生成规范](docs/asset-generation-spec.md)。
